# Grant's Website

Hey there! You've made it to the repo for my personal website, [grantmcconnaughey.com](https://grantmcconnaughey.com).
Not sure why you'd want to keep up to date on changes to it, but if you do then here's the place to be.

## Building the site

This site is built with [Astro](https://astro.build) and hosted on [GitHub Pages](https://pages.github.com/).

```sh
git clone https://github.com/grantmcconnaughey/grantmcconnaughey.github.io.git
cd grantmcconnaughey.github.io
npm install
npm run dev
```

Then open http://localhost:4321 in your browser.

Pushes to `master` are deployed automatically by GitHub Actions.
